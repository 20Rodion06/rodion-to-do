# Точка — список дел

Небольшой учебный проект на чистом HTML, CSS и JavaScript. Задачи можно добавлять, отмечать выполненными, редактировать, копировать и удалять. Есть фильтры и индикатор прогресса. Состояние сохраняется в `localStorage`.

## Как открыть

1. Распаковать ZIP **целиком** через «Извлечь все».
2. Перейти в распакованную папку `to-do-pre-main`.
3. Дважды нажать `index.html` — страница откроется в браузере. Можно также воспользоваться Live Server в VS Code.

**Не открывайте `index.html` внутри ZIP-архива:** браузер может не прочитать связанные CSS, шрифты и изображения, и оформление нарушится.

## Структура

Сохранена исходная учебная структура: `index.html`, `index.css`, `index.js`, `normalize.css`, каталоги `blocks/`, `fonts/`, `images/`. Все существовавшие CSS-файлы и подпапки находятся на прежних местах, основные классы именуются по БЭМ. Новых файлов или каталогов не добавлено.

- `index.html` — семантическая разметка, форма, список, шаблон задачи.
- `index.css` — единая точка подключения CSS-компонентов.
- `blocks/` — стили блоков, элементов и модификаторов по БЭМ.
- `index.js` — управление задачами, фильтрация, обновление счётчиков и сохранение данных.
- `fonts/` и `images/` — локальные ресурсы исходного проекта.

## Особенности

- Редактирование: нажать на значок карандаша, ввести текст, нажать Enter для сохранения; Escape отменяет изменение.
- Хранилище использует ключ `toDoTasks`, как в исходной версии. Старые данные в виде массива строк поддерживаются.
- Никаких сборщиков, библиотек, внешних ссылок или сетевых зависимостей нет.
